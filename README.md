# Accounting System

A beginner-level accounting system developed using Java and Java Swing.

## 📌 About the Project

This project is a simple banking system that allows users to create bank accounts, set an initial balance, transfer money between accounts, and delete accounts.

The system automatically updates the balance of both accounts after each transaction.

## 🖼️ Screenshot

![Accounting System](https://github.com/aminscodes/accounting-system/blob/main/image.png%20(2).jpeg?raw=true)

## ✨ Features

- Create a bank account
- Set an initial balance
- Transfer money from one account to another
- Automatically update account balances after transfers
- Delete a bank account
- Display account information

## 🛠️ Technologies Used

- Java
- Java Swing

Possible future improvements include:
